## 1. Locked Feature Scope for MVP

### Pillar 0: Cross-Tool Orchestration Intelligence
- **Defining Capability**: Prism acts as a personal assistant that orchestrates tools together in a single conversation turn, not just a connector.
- **Autonomous Chaining**: The agent intelligently chains actions across multiple connected services without requiring prompt engineering for each step.
- **Examples**:
  - Pulling data from a CRM, analyzing it, and drafting an email via an email client.
  - Summarizing records from multiple disjoint systems into a unified status report.

### Pillar 1: High-End Hardware-Grade Cockpit UI
- Zero AI-Slop Guarantee, 3-Panel Asymmetric Layout, Interactive Input Bar.

### Pillar 2: Universal Tool Integration (Prism Connect Hub)
- 1-Click Tool Drawer, 100% White-Labeled Flow, Per-User Isolation.

### Pillar 3: Real-Time Live Stack Radar (Telemetry)
- Webhook Ingestion, Live Stream Delivery, Ambient Alert Pills.

### Pillar 4: Direct Agent Streaming (Zero n8n)
- Native LLM Engine, Sub-Second TTFT, Tool Calling.
- Multi-Step Tool Chaining: Capable of streaming responses and tool execution sequentially.
- UX Integration: Shows smooth inline thinking indicators and orchestration step events during tool execution.

### Pillar 5: Human-in-the-Loop Sign-Off
- Action Proposal Cards, Audit Ledger.

## 2. Explicitly Deferred (Post-MVP)
- ❌ Advanced orchestration patterns (e.g., parallel tool execution, complex conditional branching).
- ❌ Virtual computer / browser automation sandboxes.
- ❌ Native Teams/Slack bot packaging.
- ❌ Real-time bidirectional voice agent.
- ❌ Organization settings.

## 3. Definition of Done (Acceptance Criteria)
1. **Sign-up & Connect**: User successfully signs up and connects at least two different tool services.
2. **Brand Audit**: 100% adherence to Prism brand sovereignty.
3. **Cross-Tool Orchestration Test 1 (Query to Action)**: User asks for a status list from one tool, and when instructed, the agent successfully stages batch actions in a secondary communication tool.
4. **Cross-Tool Orchestration Test 2 (Data Synthesis)**: User asks for a synthesized report and the agent successfully pulls and merges data from at least two distinct connected tools.
5. **Approve Action**: Human-in-the-loop action approval works seamlessly.
6. **Webhook Test**: Real-time stack radar correctly ingests and displays alerts.
7. **UI Quality**: High-end hardware-grade UI standards met, including visible inline thinking/orchestration indicators during multi-tool workflows.
8. **Build Check**: All services build and deploy cleanly.
